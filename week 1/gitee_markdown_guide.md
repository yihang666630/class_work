# Gitee Markdown 渲染效果指南（与 GitHub 兼容）

本文档将介绍如何在 Gitee 平台使用 Markdown 语法，实现与 GitHub 类似的文档渲染效果，包含各类格式的具体用法和示例。


## 一级标题
============

本示例参考自 [Zack Story 的 GitHub 示例](https://gist.github.com/rt2zz/e0a1d6ab2682d2c47746950b84c0b6ee)。

Gitee 的内置 Markdown 渲染器虽与 GitHub 存在细微差异，但核心功能一致，大部分格式可无缝兼容。

完整的 Gitee Markdown 语法可参考官方指南：[《Gitee 帮助中心 - Markdown 语法》](https://gitee.com/help/articles/4136)。


### 段落与基础格式
段落之间需用空行分隔。

这是第二段文本。可使用 *斜体*、**粗体** 和 `等宽代码` 格式。

无序列表示例：
  * 列表项 1
  * 列表项 2
  * 列表项 3

注意：列表文本需从星号后第 3 个字符位置开始（即左侧缩进 4 个字符）。


### 块引用与特殊符号
块引用格式：
> 这是块引用内容
> 可以跨多行显示
>
> 空行可用于分隔引用内的段落

符号用法：
- 三个连字符 `---` 显示为长破折号（——）
- 两个连字符 `--` 表示范围（如：章节 12--14）
- 三个点 `...` 自动转换为省略号（…）
- 支持 Unicode 字符（如：☺、©、€）


## 二级标题
------------

### 有序列表
有序列表示例：
 1. 第一项
 2. 第二项
 3. 第三项

同样需注意：列表文本从编号后第 3 个字符位置开始（左侧缩进 4 个字符）。


### 代码块
#### 缩进式代码块
通过缩进 4 个空格表示代码块：
    # 示例代码
    for i in 1 .. 10 { do-something(i) }

#### 分隔符代码块
使用 `~~~` 或 ``` 包裹代码块（更便于复制）：
~~~
define foobar() {
    print "欢迎使用 Gitee 代码块";
}
~~~

#### 语法高亮
在分隔符后指定语言名称可实现语法高亮：
~~~python
import time
# 计数到 10 的示例
for i in range(10):
    time.sleep(0.5)  # 延迟 0.5 秒
    print(i)
~~~


### 三级标题 ###

#### 嵌套列表
嵌套列表示例：
 1. 首先准备食材：
      * 胡萝卜
      * 芹菜
      * 小扁豆
 2. 烧开水
 3. 按以下步骤操作：
        1. 找到木勺
        2. 打开锅盖
        3. 搅拌食材
        4. 盖上锅盖
        5. 将木勺放在锅柄上
        6. 等待 10 分钟
        7. 重复步骤 2-6（完成后关火）
    
    注意：不要碰到木勺，以免掉落。

嵌套规则：子列表需比父列表多缩进 4 个字符。


#### 链接
链接格式示例：
- 外部链接：[Gitee 官网](https://gitee.com)
- 本地文件链接：[本地文档](local-file.md)
- 页内锚点链接：[跳至二级标题](#二级标题)（锚点为标题文本小写，空格替换为 `-`）


#### 表格
表格格式：

| 尺寸 | 颜色  | 材质       |
|------|-------|------------|
| 9    | 棕色  | 皮革       |
| 10   | 黄色  | 聚酯纤维   |
| 10   | 黑色  | 小山羊皮   |

表：鞋子尺寸与材质对照表（表格标题）

提示：可用 [Markdown 表格生成器](https://www.tablesgenerator.com/markdown_tables#) 快速创建表格。


#### 图片
图片插入格式：
![示例图片描述](https://i.guim.co.uk/img/media/43352be36da0eb156e8551d775a57fadba8ae6d7/0_0_1440_864/master/1440.jpg?width=1200&height=1200&quality=85&auto=format&fit=crop&s=1829611852af3ffc6460b4068e20bcbc "图片标题（悬停时显示）")

建议：图片优先存储在 Gitee 仓库内（路径格式：`./images/pic.jpg`），避免外部链接失效。


#### 数学公式
行内公式：$\omega = d\phi / dt$

独立公式（需用双美元符号包裹）：
$$I = \int \rho R^{2} dV$$

Gitee 支持 LaTeX 语法的数学公式渲染，无需额外配置。


#### 转义字符
如需显示 Markdown 语法中的特殊符号（如 `*`、`_`、`` ` ``），可在前面加反斜杠 `\`：
- 显示 `*斜体*` 而非斜体：\*斜体\*
- 显示 `` `代码` `` 而非代码格式：\`代码\`


## Gitee 操作提示
1. **创建文档**：在 Gitee 仓库中新建 `.md` 后缀的文件（如 `README.md`）即可
2. **实时预览**：编辑时点击「预览」按钮可实时查看效果
3. **提交生效**：保存并提交后，仓库页面会自动渲染最新的 Markdown 内容

通过以上方法，即可在 Gitee 实现与 GitHub 一致的 Markdown 文档效果。
