# Terminal Commands

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | shows the all the contents or files in current directory |
|     cd directory_name       | change the directory path to the directory named cirectory_name |
|     cd ..                   | change or nevigate up the directory to the parent directory |
|     cd -                    | go back to the directory path where you're just in |
|     mkdir directory_name    | add a new directory named directory |
|     touch filename          | add a new file named filename |
|     git status              | check the status or changes of your repository, like which file is changed for stage but not comitted and saved |
|     git add -A              | tell the git you've changed stages and would like to save |
|     git commit -m ""        | bundles the changes into one commit to create a save point |
|     git push                | upload the already saved or committed changes to romote |
|     git pull                | you can "pull" your collogues' latest changed repository to your own computer to sync up |
